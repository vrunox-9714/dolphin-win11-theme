01
Phase 01 Layout

Structural layout realignment
& toolbar sequencing

1
Nest the address bar inside each tab

By default Dolphin renders a single global location bar above all tabs, which looks disconnected from individual tab states. Removing it forces Dolphin to render a dedicated, local address bar inside each tab header — matching Windows 11's per-tab address behavior.

  1. Right-click the Dolphin toolbar → Configure Toolbars…
  2. In the right-hand "Current Actions" panel, find Location Bar and click the left arrow to remove it.
  3. Click Apply. Dolphin automatically activates per-tab address bars as a fallback.
  4. Go to Configure Dolphin… → Startup → New windows and check Make location bar editable.
This single change is the foundation of all tab-level layout work. Without it, the address bar will remain globally shared and won't reflect individual tab navigation state.
2
Build the primary navigation toolbar row

Open Configure Toolbars… and arrange the top row with these exact actions and display modes, matching the Windows 11 address bar visual sequence:

3
Build the secondary command bar (file operations)

In Configure Toolbars…, populate a second toolbar row with these actions in order. This replicates the flat context-sensitive command strip beneath the address bar in Windows 11:

Toolbar action sequence
[ + New  (new_dir) ]  [ Cut (edit_cut) ]  [ Copy (edit_copy) ]
[ Paste (edit_paste) ]  [ View (view_menu) ]

All actions should be set to Icon Only with no text labels, to match the minimal Windows 11 command bar aesthetic.

02
Phase 02 Tab Bar

Chrome-style tab bar
implementation

4
Intercept the native titlebar via KWin rule

KDE Plasma uses server-side decorations (SSD) by default, which blocks custom tab bars from rendering inside the window title area. You must force-remove the titlebar for Dolphin specifically via a KWin application rule.

  1. Go to System Settings → Window Management → Window Rules
  2. Click Add New…
  3. Set Window class (application) to org.kde.dolphin, match: Exact Match
  4. Under Appearance & Fixes, add property: No titlebar and frame → set to Force → Yes
  5. Click Apply and restart Dolphin
You will lose the standard Minimize/Maximize/Close buttons. To restore them, install the Klassy window decoration suite and configure a global window controls panel widget, or add them to the system top bar.
5
Style QTabBar for trapezoidal Chrome-style tabs

With the titlebar gone, Dolphin's internal tab widget can now occupy the top of the window. Apply the following QSS to ~/.config/dolphin.qss to transform flat square tabs into angled, sloped Chrome/Fluent-style tabs:

QTabBar styles — ~/.config/dolphin.qss (tab section)
/* Base tab bar container — matches Windows light theme background */
QTabBar {
    background: qlineargradient(
        x1:0, y1:0, x2:0, y2:1,
        stop:0 #F3F3F3, stop:1 #EAEAEA
    );
    border-bottom: 1px solid #D5D5D5;
}

/* Inactive tabs — sloped trapezoidal shape with top-radius and overlap */
QTabBar::tab:!selected {
    background: qlineargradient(
        x1:0, y1:0, x2:0, y2:1,
        stop:0 #E5E5E5, stop:1 #DCDCDC
    );
    color: #454545;
    border: 1px solid #C0C0C0;
    border-bottom-color: none;
    border-top-left-radius: 8px;
    border-top-right-radius: 8px;
    padding: 6px 20px;
    margin-right: -4px;
    margin-top: 4px;
}

/* Active tab — white Fluent surface with blue accent underline */
QTabBar::tab:selected {
    background: #FFFFFF;
    color: #1A1A1A;
    border: 1px solid #D5D5D5;
    border-bottom: 2px solid #005A9E;
    border-top-left-radius: 8px;
    border-top-right-radius: 8px;
    padding: 8px 24px;
    margin-top: 0px;
}

/* Hover transition on inactive tabs */
QTabBar::tab:!selected:hover {
    background: qlineargradient(
        x1:0, y1:0, x2:0, y2:1,
        stop:0 #EDEDED, stop:1 #E2E2E2
    );
    border-color: #B5B5B5;
}
6
Add an inline "+" new-tab button

Dolphin's QTabBar does not natively render an inline "+" button at the end of the tab strip. Implement one by binding a toolbar button to the new_tab action and positioning it adjacent to the tab bar via QSS.

  1. In Configure Toolbars…, add a button bound to action new_tab (also triggered by Ctrl+T).
  2. Set it to Icon Only, positioned at the far right of the tab bar row.
  3. Add the following to your dolphin.qss:
New tab button QSS — append to ~/.config/dolphin.qss
/* Transparent "+" button sitting beside the tab strip */
QToolButton#new_tab_action {
    background: transparent;
    border: 1px solid transparent;
    border-radius: 4px;
    width: 24px;
    height: 24px;
}

QToolButton#new_tab_action:hover {
    background: rgba(0, 0, 0, 0.08);
    border: 1px solid rgba(0, 0, 0, 0.15);
}

Phase 03 Theme

Fluent theme & iconography
integration

7
Disable alternating row colors via kdeglobals

Dolphin's default view uses alternating row background colors. Windows 11 uses a flat solid-white file list. Disable the striping by making both background values identical in the KDE color config.

  1. Open ~/.config/kdeglobals in a text editor.
  2. Find (or create) the [Colors:View] block.
  3. Set both values as shown:
~/.config/kdeglobals — [Colors:View] block
[Colors:View]
BackgroundNormal=255,255,255
BackgroundAlternate=255,255,255
If you use the Kvantum theme engine, it overrides kdeglobals. You must also open ~/.config/Kvantum/<ThemeName>/<ThemeName>.kvconfig and verify that base.color and alt.base.color are set to the same value.
~/.config/Kvantum/<Theme>/<Theme>.kvconfig — relevant keys
base.color=#FFFFFF
alt.base.color=#FFFFFF

Install Win11 icon theme & Willow action overlays

Replace Dolphin's default icon set with Windows 11 navigation glyphs, folder icons, and action buttons:

cp -r Win11-icon-theme/Win11 ~/.local/share/icons/Win11/

# Overlay Willow theme action arrows
git clone https://github.com/doncsugar/willow-theme.git
cp willow-theme/willow-icons/actions/22/* \
   ~/.local/share/icons/Win11/actions/22/

# Refresh icon cache

  2. Select Win11 from the list and click Apply
The Willow overlays specifically replace the navigation arrows (back, forward, up) with Windows-accurate glyphs that the base Win11 pack does not include.

10
Load the stylesheet persistently via the .desktop launcher

The stylesheet must be passed as a flag every time Dolphin launches. Edit the desktop entry so all launch paths (app drawer, taskbar, Super menu) automatically apply it:

Terminal — copy and patch the desktop entry
# Copy system entry to user-local override location
cp /usr/share/applications/org.kde.dolphin.desktop \
   ~/.local/share/applications/org.kde.dolphin.desktop

# Edit the Exec line
nano ~/.local/share/applications/org.kde.dolphin.desktop

Find the line starting with Exec= and update it to:

~/.local/share/applications/org.kde.dolphin.desktop — Exec line
Exec=dolphin --stylesheet ~/.config/dolphin.qss %u
Keep %u at the end — it passes file/folder URI arguments so Dolphin still opens correctly when you click a folder in another app. Omitting it breaks file association launches.
Terminal — refresh desktop database
update-desktop-database ~/.local/share/applications/
Final Verification

Verification
checklist

✓
Confirm all changes are applied correctly

After a full Dolphin restart, verify each of the following:

  • Address bar appears inside each tab header — not globally above the tab strip
  • Top row shows: Back / Forward / Up / Reload / Home — then address — then Search
  • Second toolbar row shows: New / Cut / Copy / Paste / View
  • Window has no OS titlebar; tabs render at the very top of the window frame
  • Active tab is white and raised; inactive tabs are gray and recessed with overlap
  • File list background is solid white — no alternating row colors
  • Sidebar is #F9F9F9 with a right border separating it from the file view
  • Scrollbars are 8px thin with rounded handles
  • Context menus are white with rounded corners and no harsh borders
  • Icons render Windows 11 glyphs for folders, drives, and toolbar actions
If the stylesheet doesn't appear to be loading, run dolphin --stylesheet ~/.config/dolphin.qss directly in a terminal to check for QSS parse errors in the output.
